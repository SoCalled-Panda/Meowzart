
# Meowzart

Meowzart is a cozy mobile rhythm game where you play classical melodies with a cat choir. Tap notes as they fall through four lanes; each accurate hit plays a meow tuned to the note. Keep your cat in good spirits, build a combo, and earn up to three stars.

## Features

- Rhythm gameplay with timing judgements, combos, and a gentle mood system
- Selectable cats, song results, and local progress
- Classical charts for Canon in D, Ode to Joy, and Vivaldi's Summer
- Offline play, built with Flutter, Dart, and Flame

## Run locally

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) with Dart, then from the project directory run:

```sh
flutter pub get
flutter run
```

Run the test suite with:

```sh
flutter test
```
